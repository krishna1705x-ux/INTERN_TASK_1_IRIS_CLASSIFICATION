INTERN_TASK_1_IRIS_CLASSIFICATION
Iris Flower Classification
Project Overview
This project is part of my Machine Learning Internship.
The objective is to classify Iris flowers into three species — Setosa, Versicolor, and Virginica — based on their sepal and petal measurements using supervised machine learning. Problem Statement
Given four features of an Iris flower:
Sepal Length
Sepal Width
Petal Length
Petal Width
Build a machine learning model that accurately predicts the species of the flower.
Tools & Technologies Used
Python
Pandas – data handling
NumPy – numerical computations
Matplotlib & Seaborn – data visualization
Scikit-learn – ML models & evaluation
Jupyter Notebook / VS Code
 Workflow
Loaded Iris dataset from sklearn.datasets
Performed Exploratory Data Analysis (EDA)
Split dataset into training & testing sets
Applied feature scaling using StandardScaler
Trained a Logistic Regression model
Evaluated model using accuracy & confusion matrix
Saved trained model using Pickle
 Model Performance
Algorithm Used: Logistic Regression
Accuracy Achieved: ~97% – 100% (depending on train-test split)
 Results
The model successfully classifies Iris flowers with high accuracy, demonstrating the effectiveness of supervised learning techniques on structured datasets.
Conclusion
This project demonstrates the complete end-to-end machine learning pipeline including data loading, preprocessing, model training, evaluation, and saving the model.
The Iris dataset is ideal for understanding basic classification concepts in machine learning.
